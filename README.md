# AB Website Starter

A simple, clean website template designed for A/B testing and experimentation.

## Features

- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **A/B Testing Ready**: Built-in JavaScript functionality to randomly assign users to different variants
- **Clean, Modern UI**: Professional styling with smooth scrolling navigation
- **Form Handling**: Contact form with basic validation
- **Easy Customization**: Well-structured HTML, CSS, and JavaScript files

## Files

- `index.html` - Main HTML structure
- `style.css` - Stylesheet with responsive design
- `script.js` - JavaScript functionality including A/B testing logic

## A/B Testing

The website automatically assigns visitors to either variant A or B:
- **Variant A**: Default blue theme with "Get Started" button
- **Variant B**: Purple theme with "Start Now" button in red

## Usage

1. Open `index.html` in a web browser
2. Navigate through different sections using the header menu
3. Test the contact form and CTA button functionality
4. Refresh the page to see different A/B test variants

## Customization

Modify the CSS variables and JavaScript logic to create your own A/B test variations. The framework is designed to be easily extensible for more complex testing scenarios.
