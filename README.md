# All Business Portal - Request Submission System

A web-based portal for submitting requests to Business Managers (BM) and Vice Presidents (VP).

## Features

- **Professional Design**: Clean, responsive web interface with modern styling
- **Request Submission Form**: Comprehensive form for submitting business requests
- **Recipient Selection**: Choose to submit to Business Manager, VP, or both
- **Priority Levels**: Set priority levels (Low, Medium, High, Urgent)
- **Form Validation**: Client-side validation with real-time feedback
- **Auto-save**: Form data is automatically saved as draft to prevent data loss
- **Success Confirmation**: Unique request ID generation and confirmation messages
- **Mobile Responsive**: Works seamlessly on desktop and mobile devices

## Form Fields

### Required Fields
- **Your Name**: Requester's full name
- **Your Email**: Valid email address for confirmation
- **Submit to**: Choose recipient type (BM, VP, or both)
- **Priority Level**: Request urgency level
- **Subject**: Brief description of the request
- **Request Details**: Detailed information about the request

### Optional Fields
- **Department**: Requester's department
- **Expected Outcome**: What resolution is expected
- **Deadline**: Target completion date

## Files

- `index.html` - Main website structure and form
- `styles.css` - Responsive CSS styling
- `script.js` - Form validation and submission logic

## Usage

1. Open `index.html` in a web browser
2. Fill out the request form with required information
3. Select appropriate Business Manager/VP as recipient
4. Set priority level and provide detailed request information
5. Submit the form to receive a unique request ID

The system provides immediate feedback and generates a unique request ID for tracking purposes.
